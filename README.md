# Bellabeat Case Study: Smart Device Usage Analysis

## Overview
This project analyzes smart device usage data to identify trends in user activity and provide marketing recommendations for Bellabeat.

## Tools Used
- R (data cleaning, analysis, and visualization)
- tidyverse (including dplyr for data manipulation and ggplot2 for visualization)
- dplyr (data wrangling: group_by, summarise, mutate, filtering)
- ggplot2 (data visualization and trend analysis)

## Key Findings
- Activity levels vary across the week
- Higher steps correspond with higher calorie expenditure
- Sundays show lower engagement

## Recommendations
- Targeted engagement reminders on low-activity days
- Personalized fitness insights
- Marketing focused on consistent activity tracking
